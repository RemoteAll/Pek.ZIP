> **开工先读（存在则读，按序）**：`.github/copilot-instructions.md` → 本文 → `docs/用户档案.md` → `docs/项目记忆.md` → `docs/决策记录.md` 最新节。

## 1. 项目速览

- **定位**：国内 + 国外离线 IP 定位库的 Zig 实现；国内 ip2region xdb v3，国外 MaxMind/DB-IP MMDB，兼容 C# 纯真 `ip.gz`。
- **形态**：库模块 `pek_zip` + CLI `zpk` + 基准 `zpk-bench`。
- **技术栈**：Zig 0.17.0；零第三方依赖。
- **仓库**：`G:\Code\Zig\Pek.ZIP`（本机新建，远端待配置）。
- **参考实现**：`G:\Code\Rust\Pek.IP`（Rust，逐模块对照）、`G:\Code\Pek.FrameWork\DH.NIP`（C#，纯真/在线/CSV）。

### 模块总览（`src/`）

| 文件 | 职责 |
|------|------|
| `root.zig` | 对外入口与模块组织 |
| `ip.zig` | IP 解析/格式化、IPv4-mapped 归一、特殊地址分类（`IpClass`） |
| `blob.zig` | **数据文件视图唯一实现**：mmap 只读 / 堆读入 / 借用 + 生命周期 |
| `xdb.zig` | ip2region xdb v3（IPv4/IPv6，Vector/BTree，零分配） + 测试用最小 xdb 构造器 |
| `mmdb.zig` | MaxMind DB（City/Country/ASN/ISP；24/28/32 位记录；pointer/容器解码） |
| `qqwry.zig` | 纯真 QQWry（`ip.gz` gzip 直读；`0x01/0x02` 重定向；GBK→UTF-8 写 scratch） |
| `gb2312.zig` | GBK↔Unicode（`src/gb2312.bin` 由 `tools/gen_gbk_table.ps1` 生成） + 反向编码器 |
| `region.zig` | xdb 地域串解析（v3，兼容 v2），零拷贝 |
| `country.zig` | ISO→中文 / 洲→中文 / 中文名→ISO（编译期排序 + 二分） |
| `locator.zig` | 双源合并、特殊地址短路、统一 `Location`（`displayShort`） |
| `config.zig` | `Config/Ip.toml`（顶层 `Key = value` 子集；首次运行生成模板） |
| `catalog.zig` | `/components/catalog.json` 解析、选包（any 优先 / 版本比较） |
| `http.zig` | `std.http.Client` 薄封装（系统根证书 + 自定义 CA；GET/POST/GET 到文件） |
| `store.zig` | 下载缓存：SHA-256 校验 → 解压 → `.pek-zip.json` → 版本清理 |
| `manager.zig` | **启动异步**：本地立即可用 + 后台补缺 + 原子热替换 + 数据集状态 |
| `main.zig` | CLI：`lookup` / `sync` / `selfcheck` / `mkxdb` / `version` |

## 2. 数据文件

- 本地命名（不区分大小写）：`ip2region_v4.xdb`（兼容 `ip2region.xdb`）/ `ip2region_v6.xdb` / `*city*.mmdb` / `*country*.mmdb` / `*asn*.mmdb` / `*isp*.mmdb` / `ip.gz`（也认 `qqwry.dat`、`ip.dat`）。
- 下载缓存：`{CacheDir}/{dataset}/{version}/` + `.pek-zip.json`（id/version/sha256/installedAt/files）。
- 数据集 id：`ip2region-v4` / `ip2region-v6` / `geolite2-city` / `geolite2-asn`；平台分类 `ip-database`、target `any`。
- **数据不入库**（`.gitignore`），本机实测数据：
  - `G:\Code\Rust\Pek.IP\data\`（ip2region v4/v6 + dbip country/asn）
  - `G:\Code\Pek.FrameWork\DH.NIP\ip.gz`（纯真）

## 3. 常用命令

```powershell
zig build
zig build test
zig test src/root.zig
zig build bench -- 'G:/Code/Rust/Pek.IP/data' 200000
.\zig-out\bin\zpk.exe selfcheck --base .
.\zig-out\bin\zpk.exe lookup 114.114.114.114 8.8.8.8
.\zig-out\bin\zpk.exe sync --base .
.\zig-out\bin\zpk.exe mkxdb tests\data\ip2region_v4.xdb
powershell -NoProfile -ExecutionPolicy Bypass -File tools\regression.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools\gen_gbk_table.ps1
```

## 4. 改动连带影响

| 改动 | 必须做的验证 |
|------|--------------|
| `xdb.zig` | 真实 `ip2region_v4.xdb` 查 `114.114.114.114`（江苏）/ `223.5.5.5`（浙江）；合成的 v4/v6/btree 用例全绿 |
| `mmdb.zig` | 真实 `dbip-country-lite` 查 `8.8.8.8`→US/美国、`114.114.114.114`→CN/中国；`dbip-asn-lite` 查 `8.8.8.8`→AS15169 |
| `qqwry.zig` / `gb2312.zig` | 真实 `ip.gz`：`114.114.114.114` → `中国–江苏–南京`；重生成码表后跑 `gb2312` 往返用例 |
| `locator.zig` | 合并规则的 7 个用例（国内压城市保留坐标、仅 MMDB、纯真标记、ISP 回退 ASN…） |
| `store.zig` / 下载链路 | `store.zig` 的「安装真实 zip 固件」用例（哈希拒绝 → 安装 → 查找 → 开库 → 版本清理） |
| `manager.zig` | 「本地已有数据立即可用」「后台失败不阻塞」「并发热替换」三用例 |
| `tools/regression.ps1` | 自己跑一遍；改了阈值必须写进决策记录 |
