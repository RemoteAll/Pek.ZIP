### Zig 0.17 踩坑（本项目实际遇到）

- `std.Thread.Mutex` 已移除；用 `std.atomic.Mutex`（tryLock + spinLoopHint）或 `std.Io.Mutex`（需 io，返回 Cancelable）。
- 数组重复写法 `{0} ** n` 会报 "whitespace on one side"；改用 `@splat`。
- `std.mem.trimLeft`、`std.fmt.fmtSliceHexLower` 已移除；用 `std.mem.trim` / 手写 hex。
- `Dir.rename` 是方法：`old_dir.rename(old_sub, new_dir, new_sub, io)`（io 在最后）。
- `File` 无 `readToEndAlloc`；用 `file.reader(io, &buf)` + `reader.interface.allocRemaining(gpa, .limited(n))`。
- 结构体字段不能与同容器函数同名（`kind` 字段 + `kind()` 访问器 → 字段改 `db_kind`）；函数参数也不能同名（改 `wanted`）。
- `inline for` 里不能 `orelse continue`（comptime 控制流）；改普通 `for` 数组。
- 编译期表排序要 `@setEvalBranchQuota(200_000)`。
- mmap：`file.createMemoryMap(io, .{ .len, .protection = .{ .read = true } })`，`mm.memory` 是 `[]align(page) u8`，销毁要 `mm.destroy(io)`。
- gzip：`std.compress.flate.Decompress.init(&input, .gzip, &window)` → `decompress.reader.allocRemaining(...)`。
- zip：`std.zip.extract(dir, &file.reader(...), .{})`（已拒绝绝对路径与 `..`）。
- CA：`client.ca_bundle.rescan(gpa, io, std.Io.Clock.real.now(io))`。

### 关键口径

- **零分配查询**：返回借用切片；QQWry 的 GBK→UTF-8 写调用方 `Scratch`。
- **Blob 唯一实现**（`src/blob.zig`）：mmap/堆/借用 + 生命周期；禁止再写第二份。
- **启动异步**：本地同步 mmap → 立即可用；后台线程下载 → 原子 swap；读方无锁；旧定位器进「退休列表」，运行期不销毁，`destroy()` 回收。
- **配了 PubKey 但验签未实现 → 拒绝下载**（不静默放行）。
- `src/gb2312.bin` 是 `tools/gen_gbk_table.ps1`（.NET CP936）生成物，勿手改。

### 性能实测（ReleaseFast，2026-11-18，20 万次/项）
